dino-trunk

Labels that know when to shrink their trunk. 🦕🐘

GitHub npm

Drag the handle at the bottom-right corner of the toolbar — or use the slider — to shrink the space. Each button retracts its label through its checkpoints, down to icon-only, and grows back when there's room.

⋯
720 px

Notice the labels don't flicker when you park the width right on a boundary — that's the built-in hysteresis: a label shrinks the moment it stops fitting, but only grows back once there's clearly room again. 

import { useRef } from 'react';
import { useCollapsingLabel } from 'dino-trunk';

const ref = useRef<HTMLButtonElement>(null);
const label = useCollapsingLabel(ref, ['Save changes', 'Save', '']);
// <button ref={ref}>💾 {label}</button>
